# Practical 6 - MAD

# Project Overview
This project is developed as part of the Mobile Application Development (MAD) practical. It demonstrates the implementation of splash screen and logo animation using Kotlin and XML in Android Studio.

## Features
- Splash Screen: Displays an introductory screen when the app starts.
- Logo Animation: Provides animated effects to the application logo.
- User-Friendly Interface: Simple and attractive UI design.
- Activity Navigation: Smooth transition between application screens.

## Project Structure
- app/: Main application module.
- java/: Contains Kotlin source code files.
- res/layout/: XML files for designing screens.
- res/anim/: Animation resource files.
- res/drawable/: Images and drawable resources.
- res/mipmap/: Application launcher icons.

#Components Used
- Kotlin: Programming language used for app development.
- Android Studio: Official IDE for Android development.
- XML Layouts: Used to design user interfaces.
- Activities: Used to manage application screens.
- Animation Resources: Used to create visual effects.

# How to Run
1. Open the project in Android Studio.
2. Allow Gradle Sync to complete.
3. Connect an Android device or start an emulator.
4. Click the Run button.
5. The application will launch successfully.
